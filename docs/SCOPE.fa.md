# محدوده و سازگاری

## سازوکار پشتیبانی‌شده

افزونه از دو امکان مستند وب‌اپ Mattermost استفاده می‌کند:

1. چرخه‌ی عمر `initialize` و `uninitialize` افزونه؛
2. تابع `registerRootComponent` با Reactای که Mattermost در `window.React`
   ارائه می‌کند.

Root Component یک کنترل‌گر کوچک سازگاری DOM را مدیریت می‌کند. چون SDK کلید
سراسری و رسمی برای RTLکردن چیدمان هسته ندارد، این بخش ماهیت best-effort دارد.
فقط زیرشاخه‌های مربوط به پیام و ویرایشگر را زیر نظر می‌گیرد، کلاس‌هایی با پیشوند
اختصاصی اضافه می‌کند و هنگام unmount یا غیرفعال‌شدن افزونه همه را پاک می‌کند.

## بخش‌های هدف

فهرست selectorهای نگه‌داری‌شده این موارد را پوشش می‌دهد:

- `.post-message__text` و فرزندان اصلی Markdown آن؛
- `.textbox-preview-area` و فرزندان اصلی Markdown آن؛
- `.markdown__paragraph-inline`؛
- توضیح کانال، عنوان کانال و برچسب کانال؛
- ویرایشگرهای `post_textbox`، `reply_textbox`، `edit_textbox` و
  `modal_textbox`؛
- ویرایشگرهای غنی معنایی با الگوی
  `[contenteditable="true"][role="textbox"]`؛
- جست‌وجوی Mattermost و ورودی Quick Switcher.

اگر یک عنصر از قبل `dir="ltr"` یا `dir="rtl"` صریح داشته باشد، افزونه آن را
دست‌کاری نمی‌کند. مقدار `dir="auto"` ممکن است با نتیجه‌ی تشخیص جایگزین شود و
هنگام توقف افزونه به همان مقدار قبلی برمی‌گردد.

## الگوریتم جهت

عدد، نشانه‌گذاری و ایموجی نویسه‌های ضعیف محسوب می‌شوند و جهت پایه را تعیین
نمی‌کنند. نخستین حرف قوی، جهت LTR یا RTL را مشخص می‌کند. پیش از این بررسی،
ارجاع‌های ابتدایی شبیه `@user`، `~channel` و `#tag` فقط از یک نسخه‌ی موقت برای
تشخیص کنار گذاشته می‌شوند. متن اصلی و محتوای DOM هیچ تغییری نمی‌کند. اگر پس از
ارجاع متن قوی دیگری وجود نداشته باشد، خود ارجاع مبنای تشخیص قرار می‌گیرد.

محدوده‌های RTL شامل عبری، عربی/فارسی، سریانی، تانا، ان‌کو، سامری، مندایی و
Presentation Formهای عربی و عبری است. قطعه‌کد و mentionهای Mattermost درون پیام
جهت‌دار به‌شکل LTR ایزوله می‌شوند.

## مرزهای شناخته‌شده

- selectorهای داخلی اجزای هسته قرارداد پایدار و عمومی نیستند؛ بنابراین یک
  بازطراحی رابط Mattermost، حتی بدون تغییر API افزونه، ممکن است به به‌روزرسانی
  نیاز داشته باشد.
- افزونه جای دکمه‌ها را تغییر نمی‌دهد، نوارهای کناری را جابه‌جا نمی‌کند، ترتیب
  flex/grid را برنمی‌گرداند و ساختار پنجره‌ها و منوها را دست‌کاری نمی‌کند.
- Focalboard/Boards، Playbooks، Calls و افزونه‌های ثالث DOM مستقل دارند و خارج
  از قرارداد selectorهای نسخه‌ی نخست‌اند.
- برنامه‌های موبایل افزونه‌های webapp را بارگذاری نمی‌کنند.
- آزمون fixture رفتار کنترل‌گر، build و شکل archive را اثبات می‌کند؛ نه عملکرد
  روی همه‌ی نسخه‌های Mattermost و همه‌ی مرورگرها را.
