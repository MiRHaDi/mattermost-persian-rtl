# پشتیبانی فارسی و راست‌به‌چپ در Mattermost

[English](README.md)

این پروژه یک افزونه‌ی مستقل و صرفاً مخصوص وب‌اپ Mattermost است که نمایش متن
فارسی و دیگر زبان‌های راست‌به‌چپ را بهتر می‌کند؛ بدون آن‌که ادعا کند تمام رابط
کاربری Mattermost را آینه‌ای و راست‌چین کرده است.

## چه چیزهایی را اصلاح می‌کند؟

- برای بدنه‌ی پیام، بلوک‌های اصلی Markdown، پیش‌نمایش، توضیح کانال و نام کانال
  جهت مناسب را به‌صورت صریح تعیین می‌کند.
- حالت دشوارِ متن دوجهته را پوشش می‌دهد: اگر پیام فارسی با یک `@mention`
  لاتین شروع شود، نام کاربری را مبنای جهت کل پیام قرار نمی‌دهد.
- هم ویرایشگر متنی قدیمی Mattermost و هم ویرایشگر غنی جدید مبتنی بر
  ProseMirror/Tiptap را پوشش می‌دهد.
- mentionها و قطعه‌کدها را در متن دوجهته ایزوله می‌کند تا ترتیب حروف کمتر به‌هم
  بریزد.
- به‌جای اجرای زمان‌بندی‌شده و مداوم، از `MutationObserver` و رویدادهای ورودی و
  فوکوس استفاده می‌کند.
- هنگام غیرفعال‌شدن افزونه، همه‌ی کلاس‌ها و ویژگی‌های `dir` متعلق به افزونه را
  به وضعیت پیشین برمی‌گرداند.

این افزونه متن پیام یا داده‌ی ارسالی را تغییر نمی‌دهد و فقط DOM نمایش‌داده‌شده
در مرورگر فعلی را تنظیم می‌کند.

## محدوده‌ی واقعی افزونه

این پروژه پوسته‌ی کاملاً راست‌چین Mattermost نیست. SDK رسمی افزونه‌های وب، محل
نصب مؤلفه و یک Root Component در اختیار افزونه می‌گذارد؛ اما API پایدار و رسمی
برای وارونه‌کردن تمام چیدمان اصلی، نوارهای کناری، پنجره‌ها، منوها و محصولات
جانبی ندارد. دست‌کاری سراسری این اجزای داخلی با هر نسخه‌ی Mattermost ممکن است
بشکند.

نسخه‌ی فعلی عمداً کارهای زیر را انجام نمی‌دهد:

- روی عنصر `<html>` مقدار `dir="rtl"` نمی‌گذارد و کل ناوبری را آینه‌ای نمی‌کند؛
- ترجمه‌های اصلی رابط Mattermost را جایگزین نمی‌کند؛
- سرور، پایگاه داده، متن پیام یا پاسخ API را تغییر نمی‌دهد؛
- برنامه‌های بومی موبایل یا همه‌ی افزونه‌ها و محصولات جانبی را پوشش نمی‌دهد؛
- اجرای موفق روی سرور واقعی را، چون انجام نشده، ادعا نمی‌کند.

جزئیات فنی در [محدوده و سازگاری](docs/SCOPE.fa.md)، تفاوت شواهد کد و آزمون زنده
در [ماتریس سازگاری](docs/COMPATIBILITY.fa.md) و شواهد تصمیم‌ها در
[ممیزی upstream](docs/AUDIT.fa.md) آمده است.

## ترجمه‌ی فارسی Mattermost

زبان فارسی (`fa`) از قبل در محصولات اصلی Mattermost ثبت شده است، اما درصد
تکمیل و بازبینی ترجمه‌ها ثابت نیست و ممکن است بخشی از رشته‌ها هنوز ناقص باشند.
طبق روند رسمی Mattermost، ترجمه‌ی متن‌های اصلی محصول باید در
[Weblate رسمی Mattermost](https://translate.mattermost.com/) انجام شود؛ نه در
این افزونه و نه با جایگزین‌کردن فایل‌های JSON ترجمه در یک PR مستقیم. این پروژه
عمداً کاتالوگ جایگزین ترجمه عرضه نمی‌کند. راهنمای مشارکت در ترجمه در
[روند رسمی محلی‌سازی وب‌اپ](https://developers.mattermost.com/contribute/more-info/webapp/developer-workflow/)
آمده است.

## ساخت و آزمون

به Node.js نسخه ۲۰ یا جدیدتر و npm نیاز است.

```sh
npm ci
npm run check
```

دستور `npm run check` بررسی نوع‌ها، آزمون fixtureهای DOM، ساخت bundle وب‌اپ،
ساخت بسته‌ی نصب Mattermost و کنترل فایل‌های داخل بسته را انجام می‌دهد. خروجی
قابل نصب در این مسیر ساخته می‌شود:

```text
dist/ir.mirhadi.mattermost-persian-rtl-0.1.0.tar.gz
```

نگه‌دارنده برای آماده‌سازی Release باید `npm run release:check` را اجرا کند.
این فرمان افزون بر کنترل‌های بالا، یکسان‌بودن بایت‌به‌بایت دو build، ممیزی
وابستگی‌های با شدت بالا، `dist/SHA256SUMS` و
`dist/release-manifest.json` را نیز تولید می‌کند. جزئیات در
[راهنمای انتشار](docs/RELEASING.md) آمده است.
همچنین [یادداشت Release نسخهٔ 0.1.0](docs/RELEASE_NOTES.md) و
[پیش‌نویس ارسال به Marketplace](docs/MARKETPLACE_SUBMISSION.md) تمام پیش‌نیازهای
بیرونی و آزمون زنده‌ی باقیمانده را صریح نگه می‌دارند.

## نصب

1. بسته را با `npm run check` بسازید یا خروجی یک Release را دریافت کنید.
2. در System Console به **Plugins → Plugin Management** بروید.
3. فایل `.tar.gz` را بارگذاری و افزونه‌ی **Persian and RTL Support** را فعال
   کنید.
4. اگر ترجمه‌های فارسی خود Mattermost را هم می‌خواهید، در
   **Settings → Display → Language** زبان فارسی را انتخاب کنید.

مدیر سرور باید امکان بارگذاری افزونه را فعال کرده باشد. پیش از استفاده‌ی
عملیاتی، بسته را روی سرور آزمایشی با همان نسخه‌ی Mattermost و با هر دو حالت
ویرایشگر متنی و غنی بررسی کنید.

## شواهد سازگاری

ممیزی selectorها و چرخه‌ی عمر افزونه در ۳ سپتامبر ۲۰۲۶ روی این snapshotها
تازه‌سازی شده است:

- شاخه‌ی master مخزن `mattermost/mattermost` در
  `f6f2719165ffb132e351342add570f3b1b6fd07a`؛ آخرین Release مشاهده‌شده
  `v11.10.1` است؛
- شاخه‌ی master مخزن `mattermost/desktop` در
  `9e6b8b65a9bb80f190c78a4aa8803f0067f95fd9`؛ آخرین Release مشاهده‌شده
  `v6.3.0` است؛
- شاخه‌ی main مخزن `mattermost/mattermost-mobile` در
  `bc84b6ee3aa78e9ddc7da73710e07c7d2088bfa5`؛ آخرین Release مشاهده‌شده
  `v2.43.1` است و کلاینت بومی موبایل همچنان خارج از محدوده است؛
- شاخه‌ی master قالب رسمی افزونه در
  `3296cf6fad808c2372c254cf7b64bcc8a2144e67`؛
- شاخه‌ی master مخزن Marketplace در
  `67d3240e3c5c933c07a8d9d907395b14674b3124`؛
- شاخه‌ی main مخزن `QueraTeam/mattermost-rtl` در
  `e64afd75f43a6fa660e046b7859863047b0700f3`، فقط برای ممیزی و بدون کپی کد.

آزمون‌های خودکار از DOM نمونه استفاده می‌کنند و جای آزمون مرورگری روی یک سرور
واقعی را نمی‌گیرند. حداقل نسخه در manifest برابر 9.5.0 است و تغییرات آینده‌ی
رابط ممکن است به به‌روزرسانی selectorها نیاز داشته باشد.

## حریم خصوصی و امنیت

افزونه بخش سروری ندارد، هیچ درخواست شبکه‌ای ارسال نمی‌کند و محتوایی ذخیره
نمی‌کند. آسیب‌پذیری باید از مسیر خصوصی GitHub Security Advisory گزارش شود، نه
در issue عمومی. جزئیات در [SECURITY.md](SECURITY.md) آمده است.

## انتشار و مشارکت بالادستی

مقصد مستقل این پروژه مخزن
[`MiRHaDi/mattermost-persian-rtl`](https://github.com/MiRHaDi/mattermost-persian-rtl)
است؛ نه وصله‌ای که راست‌چین‌شدن کامل هسته را ادعا کند. پس از ثبت ماتریس واقعی
سازگاری، Release عمومی، screenshot و راه تماس امنیتی خصوصی، نگه‌دارنده باید
issue رسمی
[Add plugin](https://github.com/mattermost/mattermost-marketplace/issues/new?template=add_plugin.md)
را ثبت و روند
[افزونه‌های جامعه‌ی Mattermost](https://developers.mattermost.com/integrate/plugins/community_process/)
را دنبال کند.

ترجمه‌های فارسی هسته باید از Weblate عبور کنند. تغییرات چیدمان هسته نیز به PRهای
کوچک و متمرکز در `mattermost/mattermost`، آزمون‌های upstream و تأیید نگه‌دارندگان
نیاز دارند.
