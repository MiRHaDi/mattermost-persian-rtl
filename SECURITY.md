# Security policy

## Supported versions

Only the latest released version of this plugin receives fixes.

## Reporting

Please report security issues privately to the repository owner rather than
opening a public issue. Do not include production messages, access tokens,
server URLs, or other sensitive data in a report.

## Data handling

The plugin has no server executable, makes no network requests, stores no user
data, and does not alter message payloads. It only changes direction-related
attributes and plugin-owned CSS classes in the current browser DOM.
